SUPERTUNE - pitch correction // underground edition
===================================================

MAC
 1. Unzip this folder.
 2. Right-click "Install SuperTune.command" -> Open -> Open
    (right-click is only needed the first time - it isn't from the App Store).
    If macOS still blocks it: System Settings -> Privacy & Security -> "Open Anyway".
 3. In FL Studio: Options -> Manage plugins -> Find more plugins.

WINDOWS
 1. Unzip this folder.
 2. Double-click "Install SuperTune.bat" and click Yes.
    (If you see "Windows protected your PC": More info -> Run anyway.)
 3. In FL Studio: Options -> Manage plugins -> Find more plugins.

HOW TO USE
 - Put SuperTune on your vocal's mixer insert.
 - Set KEY and SCALE to your beat's key (presets never change these).
 - RETUNE SPEED: 0 = instant hard tune, higher = more natural.
 - HYPER: instant retune + over-the-top glitch flips between notes.
 - Amount above 100% adds extra overshoot on note changes.
 - Double-click any knob to reset it.
